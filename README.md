Study Buddy
Study Buddy is a project I am building to make studying easier with the help of artificial intelligence
The main idea is simple
A student asks a question and Study Buddy gives an easy explanation
I am building this project while learning so the project will change and improve as I go
What I want it to do
Ask Study Buddy a question
Get an explanation from artificial intelligence
Keep the interface simple
Make it useful on phones and computers
Later I may add features like
Quiz generation
Study notes
Document support
Study plans
Progress tracking
Voice questions
How I am building it
I am using artificial intelligence to help me write and understand the code
I plan to use Nextjs and React for the website
I plan to use the OpenAI API for the artificial intelligence
I may use Supabase for storing information
I am using GitHub to keep the code
I may use Vercel to host the website
The technology may change as I learn more
